## 📖 Overview

Draw-Board is a feature-rich, real-time collaborative whiteboard application. Built on top of **HTML5 Canvas**, it lets users draw, write, paste images, and manage multiple independent whiteboard tabs — all in one seamless interface. Whether you're brainstorming solo, teaching a class, or working with a distributed team, Draw-Board has everything you need to bring your ideas to life.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🖊️ **HTML5 Canvas Drawing** | Smooth, responsive drawing and writing with multiple tool options |
| 🖼️ **Image Support** | Copy and paste images directly onto the canvas |
| 📑 **Multiple Tabs** | Create and manage independent whiteboard tabs in one session |
| 🔧 **Whiteboard Toolset** | Draw, erase, add shapes, insert text, and undo/redo changes |
| 📱 **Responsive Design** | Consistent experience across desktop and mobile devices |
| ⚡ **Real-Time Updates** | Powered by Socket.IO for instant collaboration |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm v8 or higher

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/RobinKumar5986/White-Board.git
cd White-Board
```

**2. Install dependencies**

```bash
npm install
```

**3. Start the application**

```bash
npm start
```

The app will be running at `http://localhost:3000` (or whichever port is configured).
